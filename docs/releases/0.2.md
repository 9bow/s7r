# s7r 0.2

s7r saves subtitles beside each input file by default in the app and CLI.
Clear “Save beside each input file” in the app to select a separate output folder.
The CLI accepts a separate folder through `--output PATH`.
Existing Settings JSON files keep their selected output folder.
An empty `outputDirectory` saves output beside each input file.

Models use `~/.cache/s7r` by default, with folders for Nemotron, Whisper, its tokenizer, and Qwen.
The app, CLI, and Python installer use this cache root.
To reuse existing models, select their parent folder or pass `--models PATH`.

The refresh icon above the file list reloads the added folders and removes deleted files.
If you add individual files, refresh reloads their parent folders.
The “Include subfolders” checkbox controls subfolder traversal during refresh.
The app includes a new microphone and subtitle icon, created with the built-in imagegen tool.
The PNG source, macOS icon, and generation prompt are in `source/Assets` in the archive.

## Limits

The app targets Apple Silicon and macOS 26 or later.
The app uses an ad-hoc signature without Apple notarization.
The archive excludes model weights and Apple language packs.
Finder drag, macOS 26 execution, and general transcription accuracy retain the limits recorded for release 0.1.
