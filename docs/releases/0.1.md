# s7r 0.1

s7r transcribes local audio and video files through a macOS app and CLI.
It targets Apple Silicon and macOS 26 or later. Runtime tests used macOS 27.0 on an M4 with 16 GB.

The release provides Korean, English, Japanese, and Mandarin speech input, with simplified or traditional Chinese output.
Nemotron is the default speech engine. Apple Speech and Whisper remain explicit alternatives.
Apple Translation and Qwen3-4B provide optional local translation.
Model downloads remain explicit. The archive does not contain model weights or language packs.

Batch processing supports files, directories, optional recursion, cancellation, collision protection, and per-file failure reporting.
Outputs include TXT, SRT, SAMI, and JSON, with source, translated, and bilingual captions.

## Recorded validation

The core suite passed 12 tests. Real model tests cover the four required languages.
The GUI and CLI produced matching text, timestamps, and SRT in the recorded parity tests.
Nemotron completed a 1803-second synthetic file with all 300 reference repetitions.
That run took 131.3 seconds and reached about 941 MB sampled resident process memory.
Apple Speech also completed the four short fixtures, video offsets, silence, contextual hints, and cancellation.
The real VLC renderer displayed and cleared bilingual SRT and SAMI captions.

File and directory selection through the dialog completed real processing.
Finder drag remains unverified. The native UI test failed before the first drag, and further execution is excluded from this release.

## Limits

The synthetic examples do not establish general accuracy on natural or noisy conversations.
Whisper missed speech in the recorded long-file test. Use Nemotron for long files.
Translation can introduce lexical or semantic errors. Review captions against the source audio.
Speaker diarization is unsupported, and Spanish has no recorded product run.
The app uses an ad-hoc signature without Apple notarization.
macOS 26 and other subtitle players did not receive separate execution tests.
